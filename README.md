## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина кофе.

```

├── index.html
├── catalog.html

├── README.md
└── .gitignore
```

## Страницы

- `index.html` — главная: приветственный блок, преимущества, популярные товары.
- `catalog.html` — каталог: категории и карточки товаров.
- `product.html` — страница товара: картинка, описание, цена, таблица характеристик, модальное окно.
- `order.html` — форма заявки.
- `contacts.html` — контакты и ссылка на заявку.

## Технологии

- HTML5
- CSS3 (переменные, Flexbox, Grid, позиционирование)
- БЭМ-именование классов
